# ADR-0001: Write it in Go

Date: 26 Nov 2026 · Status: accepted

## Context
The tool is a command-line program that people install on laptops and CI runners.
It calls several HTTP APIs concurrently. Python and Go were the candidates.

## Decision
Go.

## Consequences
- Single static binary per platform; no runtime to install. Easy Homebrew/GoReleaser
  distribution.
- Concurrency for collectors is straightforward (goroutines, `errgroup`, `context`).
- Matches the ecosystem: SigNoz and OpenTelemetry Collector are Go, so code and
  conventions are familiar to the target audience.
- Slower to prototype than Python; accepted, because the scope is small and
  well-defined.
